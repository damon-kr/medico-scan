# PRD - 병원 마케팅 컨설팅 설문 서비스

## 1. 제품 개요

### 1.1 제품명
**병원 마케팅 헬스체크** (Hospital Marketing Health Check)

### 1.2 제품 비전
병원의 마케팅 현황을 3분 만에 진단하고, 즉시 실행 가능한 개선안을 제시하여 디지털 마케팅 컨설팅으로 자연스럽게 연결하는 진단 도구

### 1.3 목표 사용자
- **Primary**: 병원장/원장 (마케팅 의사결정자)
- **Secondary**: 병원 마케팅 담당자/홍보팀

### 1.4 핵심 가치
- **Simple**: 10개 문항, 3-5분 완료
- **Actionable**: 즉시 실행 가능한 개선안 제시
- **Comparative**: BEST CASE와 비교, 경쟁병원 대비 수준 제시
- **Converting**: 자연스러운 컨설팅 전환 유도

## 2. 핵심 기능

### 2.1 적응형 설문 시스템
- 업종 선택에 따른 문항 분기
  - 피부과/성형외과: 상업적 플랫폼 관련 추가 문항
  - 일반 진료과: 지역 마케팅 중심 문항
- 응답에 따른 동적 질문 조정

### 2.2 복합 진단 시스템
- 주요 문제 유형 진단 (1개)
- 부가 문제 식별 (1-2개)
- 업종×지역 특성 분석
- 강점 영역 발견

### 2.3 비교 분석 엔진
- 동종업계 평균 대비
- BEST CASE 대비 격차 분석
- 경쟁병원 추월 시나리오

### 2.4 맞춤형 솔루션 생성
- 즉시 실행 과제 (72시간 내)
- 단기 개선안 (1개월)
- 중장기 전략 (3-6개월)
- ROI 시뮬레이션

## 3. 진단 유형 정의

### 3.1 주요 문제 유형 (7가지)

#### Type 1: 네이버 의존 과다형
- **정의**: 전체 마케팅의 70% 이상이 네이버 집중
- **스코어링**: 네이버 채널 1순위 + 비중 50% 이상
- **솔루션**: 채널 다각화, 리스크 분산

#### Type 2: 디지털 사각지대형
- **정의**: 온라인 마케팅 비중 30% 미만
- **스코어링**: 온라인 채널 3개 이하 사용
- **솔루션**: 디지털 전환 로드맵

#### Type 3: 무분별 살포형
- **정의**: 7개 이상 채널 사용하나 통합 관리 부재
- **스코어링**: 채널 7개 이상 + 측정 체계 미비
- **솔루션**: 채널 통합 관리 시스템

#### Type 4: 방치 운영형
- **정의**: 콘텐츠 업데이트 월 1회 이하
- **스코어링**: 업데이트 주기 월 1회 이하
- **솔루션**: 운영 체계 구축

#### Type 5: 성과 맹목형
- **정의**: 마케팅 효과 측정 불가
- **스코어링**: 성과 추적 "파악 안함" 선택
- **솔루션**: 측정 체계 구축

#### Type 6: 온라인 마케팅 소극형
- **정의**: 전반적 온라인 활동 미흡
- **스코어링**: 상업적 광고 미사용 + 콘텐츠 부족
- **솔루션**: 단계적 온라인 강화

#### Type 7: 원툴형
- **정의**: 과거 성과에 안주하며 단일 채널만 고집. "이것만 하면 된다"는 고정관념으로 시장 변화와 새로운 기회를 무시
- **스코어링**: 
  - 사용 채널 1-2개
  - 단일 채널 비중 80% 이상
  - "이전에 이 채널에서 성과가 좋았음" 또는 "지금 채널만으로 충분해서 시도할 필요 없음" 응답
- **솔루션**: 리스크 인식, 점진적 확장, 성과 비교 데이터 제시

## 4. 스코어링 시스템

### 4.1 점수 체계
- **총점**: 100점 만점
- **카테고리별 배점**:
  - 채널 활용도: 30점
  - 운영 관리: 25점
  - 성과 측정: 25점
  - 예산 규모: 20점

### 4.2 레벨 구분
- **Level 1 (초급)**: 0-25점
- **Level 2 (기본)**: 26-50점
- **Level 3 (중급)**: 51-75점
- **Level 4 (고급)**: 76-100점

### 4.3 상대 평가
- 업종별 평균 대비
- 지역별 평균 대비
- 규모별 평균 대비

## 5. 전환 전략

### 5.1 FOMO 메커니즘
- 경쟁병원 실시간 동향 알림
- 기회비용 계산 및 표시
- 시간 제한 프로모션 (48시간 카운트다운)

### 5.2 단계별 CTA
- **Soft**: 무료 상담 (30분)
- **Medium**: 스타터 패키지 (150만원)
- **Hard**: 정식 컨설팅 (월 300-500만원)

### 5.3 육성 시퀀스
- Day 0: 즉시 결과 + 간단 팁
- Day 1: 상세 리포트 이메일
- Day 3: 성공 사례 공유
- Day 7: 무료 상담 제안

## 6. 기술 요구사항

### 6.1 프론트엔드
- 반응형 웹 디자인 (모바일 최적화 필수)
- 원페이지 스크롤 방식
- 실시간 진행률 표시
- 부드러운 애니메이션

### 6.2 백엔드
- 진단 로직 처리
- 결과 저장 및 분석
- 이메일 자동 발송 시스템
- 리드 관리 시스템 연동

### 6.3 데이터베이스
- 설문 응답 저장
- 진단 결과 저장
- 리드 정보 관리
- 벤치마크 데이터 관리

## 7. 성공 지표 (KPI)

### 7.1 사용성 지표
- 설문 시작률: 70% 이상
- 설문 완료율: 60% 이상
- 평균 완료 시간: 5분 이내

### 7.2 전환 지표
- 이메일 수집률: 40% 이상
- 무료 상담 신청률: 15% 이상
- 유료 전환율: 5% 이상

### 7.3 만족도 지표
- 결과 유용성: 4.0/5.0 이상
- 추천 의향: 60% 이상
- 재방문율: 20% 이상

## 8. 개발 우선순위

### Phase 1 (MVP)
1. 기본 설문 시스템
2. 7가지 진단 유형
3. 결과 페이지
4. 이메일 수집

### Phase 2
1. 업종별 분기 로직
2. BEST CASE 비교
3. 이메일 자동화
4. 모바일 최적화

### Phase 3
1. 실시간 벤치마킹
2. 맞춤형 리포트 생성
3. CRM 연동
4. A/B 테스트 시스템
