# PRD - 병원 마케팅 컨설팅 설문 서비스

## 1. 제품 개요

### 1.1 제품명
**병원 마케팅 헬스체크** (Hospital Marketing Health Check)

### 1.2 제품 비전
병원의 마케팅 현황을 3분 만에 진단하고, 즉시 실행 가능한 개선안을 제시하여 디지털 마케팅 컨설팅으로 자연스럽게 연결하는 진단 도구

### 1.3 목표 사용자
- **Primary**: 병원장/원장 (마케팅 의사결정자)
- **Secondary**: 병원 마케팅 담당자/홍보팀

### 1.4 핵심 가치
- **Simple**: 10개 문항, 3-5분 완료
- **Actionable**: 즉시 실행 가능한 개선안 제시
- **Comparative**: BEST CASE와 비교, 경쟁병원 대비 수준 제시
- **Converting**: 자연스러운 컨설팅 전환 유도

## 2. 핵심 기능

### 2.1 적응형 설문 시스템
- 업종 선택에 따른 문항 분기
  - 피부과/성형외과: 상업적 플랫폼 관련 추가 문항
  - 일반 진료과: 지역 마케팅 중심 문항
- 응답에 따른 동적 질문 조정

### 2.2 복합 진단 시스템
- 주요 문제 유형 진단 (1개)
- 부가 문제 식별 (1-2개)
- 업종×지역 특성 분석
- 강점 영역 발견

### 2.3 비교 분석 엔진
- 동종업계 평균 대비
- BEST CASE 대비 격차 분석
- 경쟁병원 추월 시나리오

### 2.4 맞춤형 솔루션 생성
- 즉시 실행 과제 (72시간 내)
- 단기 개선안 (1개월)
- 중장기 전략 (3-6개월)
- ROI 시뮬레이션

## 3. 진단 유형 정의

진단 유형 및 상세 스코어링 로직은 [hospital-marketing-scoring.md](./hospital-marketing-scoring.md) 문서를 참고하세요.

### 주요 진단 유형 (7가지)
1. 네이버 의존 과다형
2. 디지털 사각지대형
3. 무분별 살포형
4. 방치 운영형
5. 성과 맹목형
6. 온라인 마케팅 소극형
7. 원툴형

## 4. 스코어링 시스템

스코어링 시스템의 상세 내용은 [hospital-marketing-scoring.md](./hospital-marketing-scoring.md) 문서를 참고하세요.

### 점수 체계 개요
- **총점**: 100점 만점
- **카테고리별 배점**: 채널 활용도(30점), 운영 관리(25점), 성과 측정(25점), 예산 규모(20점)
- **레벨 구분**: 초급(0-25점), 기본(26-50점), 중급(51-75점), 고급(76-100점)

## 5. 전환 전략

### 5.1 FOMO 메커니즘
- 경쟁병원 실시간 동향 알림
- 기회비용 계산 및 표시
- 시간 제한 프로모션 (48시간 카운트다운)

### 5.2 단계별 CTA
- **Soft**: 무료 상담 (30분)
- **Medium**: 스타터 패키지 (150만원)
- **Hard**: 정식 컨설팅 (월 300-500만원)

### 5.3 육성 시퀀스
- Day 0: 즉시 결과 + 간단 팁
- Day 1: 상세 리포트 이메일
- Day 3: 성공 사례 공유
- Day 7: 무료 상담 제안

## 6. 기술 요구사항

### 6.1 프론트엔드
- 반응형 웹 디자인 (모바일 최적화 필수)
- 원페이지 스크롤 방식
- 실시간 진행률 표시
- 부드러운 애니메이션

### 6.2 백엔드
- 진단 로직 처리
- 결과 저장 및 분석
- 이메일 자동 발송 시스템
- 리드 관리 시스템 연동

### 6.3 데이터베이스
- 설문 응답 저장
- 진단 결과 저장
- 리드 정보 관리
- 벤치마크 데이터 관리

## 7. 성공 지표 (KPI)

### 7.1 사용성 지표
- 설문 시작률: 70% 이상
- 설문 완료율: 60% 이상
- 평균 완료 시간: 5분 이내

### 7.2 전환 지표
- 이메일 수집률: 40% 이상
- 무료 상담 신청률: 15% 이상
- 유료 전환율: 5% 이상

### 7.3 만족도 지표
- 결과 유용성: 4.0/5.0 이상
- 추천 의향: 60% 이상
- 재방문율: 20% 이상

## 8. 개발 우선순위

### Phase 1 (MVP)
1. 기본 설문 시스템
2. 7가지 진단 유형
3. 결과 페이지
4. 이메일 수집

### Phase 2
1. 업종별 분기 로직
2. BEST CASE 비교
3. 이메일 자동화
4. 모바일 최적화

### Phase 3
1. 실시간 벤치마킹
2. 맞춤형 리포트 생성
3. CRM 연동
4. A/B 테스트 시스템

## 9. 리스크 및 대응

### 9.1 낮은 완료율
- **대응**: 문항 수 축소, 게임화 요소 강화

### 9.2 부정확한 진단
- **대응**: 지속적인 알고리즘 개선, 피드백 수집

### 9.3 낮은 전환율
- **대응**: CTA 메시지 테스트, 인센티브 조정
