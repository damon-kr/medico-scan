### 1. 일일 점검 체크리스트

#### 개발자 개인 체크리스트 (매일)
```markdown
### 📅 [날짜] 일일 규칙 준수 체크

#### 작업 전 체크
- [ ] 오늘 작업할 기능이 어떤 Layer 문서에 해당하는지 확인
- [ ] 해당 Layer 문서의 최신 정보 검토 완료
- [ ] 기존 설계와 충돌하지 않는지 확인

#### 작업 후 체크
- [ ] 변경된 코드와 문서 일치성 확인
- [ ] 관련 문서 업데이트 완료
- [ ] Layer 4 (progress.md) 업데이트 완료

#### 커밋 전 체크
- [ ] `npm run build` 성공 확인
- [ ] 관련 문서 동시 커밋 포함
- [ ] 커밋 메시지에 문서 변경사항 명시
```

#### 프로젝트 관리자 체크리스트 (매일)
```markdown
### 📅 [날짜] 프로젝트 관리 체크

#### 문서 일관성 체크

- [ ] 최근 변경사항의 문서 반영 상태 확인
- [ ] 미완료 작업의 진행 상황 확인

#### 팀 규칙 준수도 체크
- [ ] 팀원들의 문서 업데이트 이행률 확인
- [ ] 코드-문서 불일치 사례 점검
- [ ] 필요시 규칙 준수 가이드 제공
```

### 2. 주간 점검 프로세스

#### 매주 금요일: 문서 동기화 검증

**1단계: 자동 검증**
```bash
# TypeScript 컴파일 검증
npm run build

# 린팅 검증
npm run lint

# 타입 체크 (있는 경우)
npm run type-check
```

**2단계: 수동 검증**
```markdown
### 주간 문서 동기화 체크리스트

#### Layer 1 (Core Architecture) 검증
- [ ] types/survey.ts ↔ 03-data-schema.md 일치성
- [ ] lib/ 폴더 실제 구현 ↔ 02-domain-logic.md 일치성
- [ ] 컴포넌트 구조 ↔ 01-architecture.md 일치성

#### Layer 2 (Process & Flow) 검증
- [ ] 실제 사용자 플로우 ↔ 04-userflow.md 일치성
- [ ] 개발 가이드 실효성 ↔ 05-implementation-guide.md
- [ ] 새로운 모범 사례 반영 필요성 검토

#### Layer 3 (Documentation) 검증
- [ ] README.md 최신성 확인
- [ ] 프로젝트 소개 정확성 확인
- [ ] 기술 스택 정보 업데이트 필요성 검토

#### Layer 4 (Live Tracking) 검증
- [ ] 06-progress.md 완료 작업 정확성
- [ ] 현재 진행 작업 상태 정확성
- [ ] 다음 작업 우선순위 적절성
```

**3단계: 불일치 해결**
```markdown
### 발견된 불일치 해결 프로세스

#### 즉시 해결 (High Priority)
- Layer 1 문서의 타입 정의 불일치
- Layer 4 문서의 진행 상황 부정확
- README.md의 주요 기능 설명 오류

#### 계획적 해결 (Medium Priority)  
- Layer 2 문서의 프로세스 개선 사항
- Layer 3 문서의 부분적 정보 업데이트
- 개발 가이드의 모범 사례 추가

#### 정기 검토 (Low Priority)
- 문서 구조 개선 제안
- 새로운 규칙 도입 검토
- 자동화 도구 개선 방안
```

## 🛠️ 도구 및 자동화

### 1. 권장 도구 설정

#### Git Hooks 설정
```bash
# .git/hooks/pre-commit
#!/bin/sh
echo "🔍 문서-코드 일치성 검증 중..."

# TypeScript 컴파일 검증
npm run build
if [ $? -ne 0 ]; then
  echo "❌ TypeScript 컴파일 실패. 커밋을 중단합니다."
  exit 1
fi

# 변경된 파일 중 types/ 폴더가 있으면 문서 업데이트 확인
if git diff --cached --name-only | grep -q "^src/types/"; then
  if ! git diff --cached --name-only | grep -q "docs/03-data-schema.md"; then
    echo "⚠️  타입 정의가 변경되었지만 03-data-schema.md가 업데이트되지 않았습니다."
    echo "문서를 업데이트한 후 다시 커밋해주세요."
    exit 1
  fi
fi

echo "✅ 검증 완료. 커밋을 진행합니다."
```

#### 진행 상황 업데이트 스크립트
```bash
#!/bin/bash
# scripts/update-progress.sh

echo "📝 진행 상황 업데이트 도구"

# Git에서 최근 커밋 정보 추출
RECENT_COMMIT=$(git log -1 --pretty=format:"%s")
COMMIT_DATE=$(git log -1 --pretty=format:"%Y-%m-%d")

echo "최근 커밋: $RECENT_COMMIT"
echo "커밋 날짜: $COMMIT_DATE"

# 06-progress.md 자동 업데이트 (간단한 형태)
echo "## 📍 최근 업데이트 ($COMMIT_DATE)" >> docs/06-progress.md
echo "- $RECENT_COMMIT" >> docs/06-progress.md
echo "" >> docs/06-progress.md

echo "✅ 진행 상황 업데이트 완료"
```
