## 🔄 주요 변경 사항

### 2025-01-14: v1.0 → v2.0 업그레이드

#### 1. 진단 유형 확장
- **구버전**: 7가지 진단 유형
  1. 원툴형
  2. 네이버 의존 과다형
  3. 디지털 사각지대형
  4. 방치 운영형
  5. 성과 맹목형
  6. 무분별 살포형
  7. 온라인 마케팅 소극형

- **최신 버전**: 12가지 진단 유형 (7개 + 5개 추가)
  8. 콘텐츠 마케팅 미활용형
  9. 검색 랭킹 최적화 필요형
  10. 플랫폼 확장 필요형
  11. 지역 밀착 마케팅 부족형
  12. 예산 대비 효율 저하형

#### 2. 설문 질문 추가
- **Q13 추가**: 우리 동네 경쟁 병원 수
  - 옵션: 거의 없음 / 보통 / 많음 / 매우 많음
- **Q14 추가**: 네이버 지도 검색 순위
  - 옵션: 1-5위 / 1페이지 / 2페이지 / 3페이지 이후

#### 3. 결과 페이지 개선
- **경쟁 환경 및 노출 순위 분석** 섹션 추가
- **우리 병원 맞춤 전략** 섹션 추가 (업종×지역×상황별 조언)
- **동적 체크리스트 생성** (39개 조건 평가)

#### 4. 데이터 스키마 변경
- `surveys` 테이블에 필드 추가:
  - `competition_count` (Q13)
  - `naver_map_ranking` (Q14)
- `SurveyResponse` 타입에 필드 추가

#### 5. 문서 구조 변경
- **구버전**: 단일 README + 개별 문서
- **최신 버전**: 4-Layer 구조
  - Layer 1: 01-03 (Core - 100% 정확도 요구)
  - Layer 2: 04-05 (Process - 90% 정확도)
  - Layer 3: README (Documentation - 80% 정확도)
  - Layer 4: 06-08 (Live - 실시간 업데이트)
